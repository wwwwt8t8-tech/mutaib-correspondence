# منصة المخاطبات والمساءلات الإلكترونية – نسخة أولية

هذه نسخة واجهة تجريبية لمجمع الأمير متعب بن عبدالعزيز التعليمي.

## التشغيل
افتح `index.html` في المتصفح، أو ارفع الملف إلى مستودع GitHub Pages في جذر المستودع. لا تحتاج إلى بناء أو تثبيت.

## ما يعمل حاليًا
- إعداد مساءلة غياب من النموذج رقم 20.
- كتابة إفادة المعلم ورسم توقيع تجريبي على نفس الجهاز.
- اختيار إجراء المدير وحفظه محليًا.
- إنشاء خطاب إداري، معاينة المستندات، والطباعة أو حفظ PDF من المتصفح.
- حفظ البيانات التجريبية في `localStorage` على المتصفح نفسه.
- فتح واتساب برسالة ورابط توضيحي **غير صالح للاستخدام بين الأجهزة**.

## ما لا يعمل بعد
- لا يوجد حفظ سحابي أو مزامنة بين الأجهزة.
- رابط واتساب لا يمكّن المعلم من فتح معاملته على جهاز آخر.
- لا يوجد تحقق هوية أو صلاحيات أو توقيع إلكتروني موثق.
- لا توجد مرفقات فعلية أو إشعارات حالة أو أرشفة مركزية.
- لا تستخدم بيانات موظفين حقيقية أو وثائق حساسة في هذه النسخة.

## متطلبات الإطلاق الرسمي
1. خلفية خادم آمنة مع قاعدة بيانات وصلاحيات للمدير.
2. إنشاء رموز وصول عشوائية قصيرة العمر، تحفظ بشكل مجزأ في الخادم، لكل معاملة؛ مع رمز تحقق للمعلم وحدود للمحاولات.
3. إرسال رابط HTTPS عبر واتساب، يعرض بيانات المعاملة بعد التحقق دون كشفها في الرابط.
4. واجهة إفادة المعلم مع رفع ملفات آمن ومراقبة نوع الملفات وحجمها.
5. تخزين سجل تدقيق للأحداث وتجميد المستند بعد الاعتماد.
6. تحديد آلية توقيع إلكتروني تتوافق مع المتطلبات النظامية والجهة التعليمية.
7. نشر الواجهة على GitHub Pages، مع وضع الأسرار والمفاتيح الإدارية في الخادم فقط.

**ملاحظة:** تصميم النموذج قريب من النموذج المرفق لكنه ليس نسخة مطابقة حرفيًا أو نموذجًا رسميًا معتمدًا.


## إصلاحات نسخة 2
- يظهر نص طلب الإفادة كاملًا في شاشة المعلم.
- فصل إجراءات المدير عن شاشة إفادة المعلم.
- منع إعادة تحرير الإفادة بعد اعتمادها محليًا.
- رسالة واضحة عند فتح رابط معاملة من جهاز آخر: الربط السحابي غير مفعل.

**تنبيه أمني:** هذا نموذج أولي محلي، لا يحقق فصل صلاحيات حقيقيًا ولا يصلح لبيانات المعلمين الفعلية. يلزم خادم مصادق عليه وقاعدة بيانات ذات قواعد صلاحيات قبل الإطلاق.
